## 1. Multi-Tier Verification Framework

In accordance with Sprint 5.0B engineering standards, badge validation distinguishes between four distinct verification levels:
1. **Tier 1 — Structural URL Construction:** Correct repository owner (`mnp210`), repository name (`GitHub-Profile-Pet`), workflow filename (`.yml`), and default branch parameter (`branch=main`).
2. **Tier 2 — Repository Workflow Existence:** Confirmed presence and matching `name:` property within `.github/workflows/` in both local candidate and remote production.
3. **Tier 3 — Live GitHub SVG Rendering:** Confirmed HTTP 200 response with `Content-Type: image/svg+xml` and valid `<title>` tag generated by GitHub's badge server.
4. **Tier 4 — Latest Production Execution State:** Confirmed latest execution result on branch `main` queried via GitHub Actions API.
